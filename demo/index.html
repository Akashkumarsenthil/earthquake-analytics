BEHIND THE PROJECT

From an event feed to an analytics warehouse.

The original project ingests USGS events through Airflow into Snowflake, then uses dbt to build an event fact table and daily, regional, and hourly aggregates for a Streamlit dashboard.

USGS feed→Airflow ingestion→Snowflake RAW→dbt models→Streamlit

What this demo runs

Your browser fetches the USGS seven-day feed, validates and deduplicates it, then filters and renders these observations locally. It does not run Airflow, dbt, or Snowflake. A dated snapshot keeps the demo usable when the feed is unavailable.

Engineering work

The refinement fixes historical-task routing, paginated backfills, revision-aware event updates, dbt schema alignment, and dashboard column handling. Repository tests exercise failure cases and replay behavior.

Limits & tradeoffs

The feed is a rolling observation window, not a complete historical warehouse. Revisions replace previous values; this project does not preserve every revision. This dashboard is an educational project, not an alerting service or hazard prediction.
